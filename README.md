# בוחן תרגול ופודקאסט — מסכת אבות בראייה היסטורית ועכשווית

תרגול לקורס **מסכת אבות בראייה היסטורית ועכשווית** (04-030, ד״ר חגית עמרני, עולמות — בית הספר ליהדות ותרבות ישראלית, בר־אילן, תשפ״ז).

**▶ [בוחן התרגול](https://bohanyzahal-cyber.github.io/avot-quiz/)** — מצב תרגול עם הסברים, סימולציית מבחן, מבחן מוכנות, סינון לפי יחידה, נושא ומקור, והדפסה לתרגול על נייר.

**▶ [פודקאסט](https://bohanyzahal-cyber.github.io/avot-quiz/podcast/)** — פרק לכל יחידה בשני קולות, עם שאלות לדרך בסוף כל פרק, ופרק חזרה. אפשר להאזין בדף או להוריד לטלפון.

הקורס מתוקשב ובנוי מ־10 יחידות שנפתחות לאורך הסמסטר. בכל יחידה מצגת וסיכום שהם חומר חובה, חומרי העשרה, ופעילות השתתפות (לוח פתקים או פורום).

| מבחן מסכם | 70% | אמריקאי, בלי חומר עזר, במערכת התומקס |
| בוחן בלמדה | 20% | ציון מגן: נכנס לשקלול רק אם הוא משפר את הציון. המועד, לא סופי: יום שלישי 15.12.2026, 20:00 |
| השתתפות | 10% | לוחות פתקים, פורומים וענני מילים בסוף כל יחידה |

מפגשי זום: יום שלישי 17.11.2026 ויום שלישי 29.12.2026, 20:00–22:00.

## עריכה ובנייה

שאלות: `src/uN.js` לכל יחידה, שורה לכל שאלה, בסכמה `{l,t,s,q,o,c,e}`; מבחן המוכנות ב־`src/ready_uN.js`. בנייה: `python src/build.py` (נדרש Node.js לבדיקות המבנה, הכפילויות ואורך התשובות). הבנייה כותבת את `index.html` ועותק בתיקיית הקורס.

פודקאסט: התסריטים לעריכה ב־`podcast/scripts/plain/`, העותק המנוקד ב־`podcast/scripts/`. אחרי עריכה מעתיקים, מריצים `python podcast/nikud.py NN` ואז `python podcast/build.py NN`. נדרשים edge-tts, ffmpeg ו־ffprobe. הצינור הועתק מאתר התרגול של הקורס שיטות וכלי ניהול מתקדמים.
